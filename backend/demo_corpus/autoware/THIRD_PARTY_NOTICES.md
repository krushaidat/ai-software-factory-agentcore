## Use in this project

These files are used **read-only** as a realistic source code corpus for
demonstrating the AI Software Factory multi-agent analysis pipeline. The agents
read these files, run static analysis, and produce findings — no modifications
are made to the upstream code.

The exact files included, their sizes, and metadata are listed in `MANIFEST.json`.

## How to refresh the corpus

To re-fetch with the latest Autoware files, run the included fetch script
(see `backend/demo_corpus/README.md`).
